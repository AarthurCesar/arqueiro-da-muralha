# Arqueiro da Muralha

Jogo 3D para celular (tela vertical): um arqueiro defende a muralha contra ondas de monstros, sobe de nível, escolhe cartas e compra armas e ajudantes na loja entre as fases.

- Jogar: abra `index.html` no navegador (ou o link da Vercel).
- Tecnologia: HTML + Three.js (r128), um arquivo só.
- Futuro: empacotar como app Android com Capacitor.
